# Minimum Spanning Tree (MST)

A Minimum Spanning Tree is a tree that connects all vertices of a connected, weighted, and undirected graph using the minimum possible total edge weight.

It contains no cycle and has exactly V - 1 edges, where V is the number of vertices.

## What Does MST Do?

MST finds the minimum-cost way to connect all nodes in a network.

For example, it can be used to connect cities, computers, electrical lines, or pipelines while keeping the total connection cost as low as possible.

## Important Properties

- The graph should be connected.
- The graph should be undirected.
- The edges should have weights.
- An MST contains all vertices.
- An MST does not contain any cycle.
- An MST contains exactly V - 1 edges.
- A graph may have more than one MST.

## Applications
- Computer network design
- Road construction
- Electrical network design
- Telephone and cable networks
- Water pipeline systems
- Transportation planning
- Cluster analysis
