# Data Structures and Algorithms - II (DSA-2)

Welcome to my **Data Structures and Algorithms - II (DSA-II)** repository!

This repository contains my C++ implementations, laboratory exercises, algorithmic solutions, and practice problems from the DSA-II course. It is organized to make learning, practicing, and revising important data structures and algorithms easier.

## Topics Covered

- Vector
- Minimum Spanning Tree (MST)
- Shortest Path Algorithms
- Divide and Conquer (D&C)
- Dynamic Programming (DP)
- Greedy Algorithms
- Disjoint Set Union (DSU)
- Hash Table
- Rabin-Karp Algorithm
- Laboratory Exercises
- Practice Problems
- Algorithm Implementation and Analysis

## Development Environment

- **IDE:** Code::Blocks
- **Language:** C++
- **Compiler:** GNU GCC Compiler (G++)
- **Version Control:** Git and GitHub

All programs are written in C++ and can be compiled and executed using Code::Blocks with a properly configured C++ compiler.

## Purpose

The main purposes of this repository are to:

- Organize all DSA-II course materials and programming exercises in one place.
- Understand important data structures and algorithms through practical implementation.
- Improve logical thinking and algorithmic problem-solving skills.
- Practice implementing algorithms using C++.
- Keep track of my learning progress throughout the course.
- Build a useful reference for future revision and competitive programming.

## How to Run the Programs

1. Download or clone this repository.
2. Open Code::Blocks.
3. Select File → Open and choose the desired .cpp file.
4. Build and run the program using F9, or select Build → Build and Run.
5. Enter the required input and observe the output.

**Note:** Each program can generally be compiled independently. If a program uses multiple source files, compile them together as required.
