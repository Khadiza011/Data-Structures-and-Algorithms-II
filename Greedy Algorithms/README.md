# Greedy Algorithms

A Greedy Algorithm solves a problem by selecting the best available choice at each step.

It makes a locally optimal decision with the hope that these decisions will produce a globally optimal solution.

## What Does a Greedy Algorithm Do?

A Greedy Algorithm builds a solution step by step.

At every step, it selects the option that gives the greatest immediate benefit or the lowest immediate cost.

Unlike Dynamic Programming, a greedy algorithm usually does not reconsider its previous decisions.

## Main Properties

- Greedy Choice Property: A globally optimal solution can be reached by making the best local choice at every step.

- Optimal Substructure: The optimal solution contains optimal solutions to its smaller subproblems.
