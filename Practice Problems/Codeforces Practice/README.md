# Codeforces Practice - DSA II

This folder contains my solutions to different Codeforces problems practiced as part of **Data Structures and Algorithms II (DSA II)**.

The solutions are written in **C++** with simple and beginner-friendly implementations.

## Topics Covered

- Arrays
- Strings
- Sorting
- Binary Search
- Prefix Sum
- Greedy Approach
- STL Vector
- Counting and Frequency
- Basic Problem Solving

## Language

```text
C++
```

## Purpose

The purpose of this collection is to improve problem-solving skills and practice important DSA concepts through Codeforces problems.
